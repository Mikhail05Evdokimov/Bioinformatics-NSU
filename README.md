Омепразол

Действующее вещество - омепразол.

Область применения: применяется при желудочной язве и язве двенадцатиперстной кишки, гастроэзофагеальной рефлюксной болезни, синдроме Золлингера-Эллисона. Продаётся в виде растворимых капсул для приёма внутрь. Не предназначен для детей.

Механизм действия: всасывается в париетальные клетки желудка и тормозит Водородно-калиевую аденозинтрифосфатазу, тем самым блокирую секрецию соляной кислоты. (Замедляет действие протонного насоса в париетальных клетках желудочных желез, благодаря чему осуществляется блокада переноса ионов водорода и последняя фаза синтеза желудочной соляной кислоты).

В результате выполнения блокнота получилось много промежуточных файлов и файлы докинга (папка 7ZUB), а также несколько 3D визуализаций (папка images).
